# Exumo website

Marketing site for Exumo — AI sales agents for B2B exporters.

Built with Next.js 16, Tailwind CSS 4, Motion and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Where things live

- `app/page.tsx` — section order
- `components/` — one file per section (Hero, ChatDemo, Demo, Agents, Results, Industries, Voices, Team, FinalCta)
- `lib/site.ts` — demo booking link and contact email
- `public/images`, `public/videos` — photos, product screenshots, hero video
